# Pulsar Agency

Односторінковий сайт маркетингового агентства — CRM, реклама, AI та аналітика.

React + Vite, повністю статичний, без бекенду.

## Локальний запуск

```bash
npm install
npm run dev      # http://localhost:5174
npm run build    # продакшн-збірка в dist/
```

## Деплой

```bash
npm run deploy   # збірка та публікація на GitHub Pages
```
